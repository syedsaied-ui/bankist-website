# Bankist Website

A modern landing page for a fictional bank with smooth animations and interactive components.

## 🚀 Features
- Smooth scrolling navigation
- Sticky navbar
- Lazy loading images
- Tabbed components
- Slider

## 💻 Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Open the project folder
2. Double click "index.html"

OR (recommended):
Use VS Code Live Server
